# CODE//CORE — Formação Prática de Programação

Site completo e responsivo para o infoproduto de programação **CODE//CORE**, desenvolvido com foco em alta fidelidade visual, navegação entre 5 páginas e animações tecnológicas modernas.

## 🚀 Tecnologias

- **React 18** + **TypeScript**
- **Vite**
- **React Router DOM v6** (5 rotas independentes)
- **Lucide Icons**
- **Vanilla CSS** (Design System dark tech com variáveis e suporte a `prefers-reduced-motion`)
- **Canvas** (Animação de partículas de código no background)

## 🌐 Páginas e Rotas

- `/` — **Início**: Hero com notebook orientado à esquerda, benefícios, problemas, resumo do método, o que você recebe, depoimentos, painel de oferta e FAQ.
- `/metodo` — **O Método**: Detalhamento das 4 etapas de aprendizado com códigos de exemplo.
- `/conteudo` — **Conteúdo**: Grade completa dos módulos com dropdowns e recursos inclusos.
- `/depoimentos` — **Depoimentos**: Experiências detalhadas de alunos verificados e CTA de jornada.
- `/faq` — **FAQ**: Perguntas frequentes interativas e canal de suporte.

## 💻 Como Rodar o Projeto

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Para gerar o build de produção:
   ```bash
   npm run build
   ```
